РЕКОМЕНДУЕМАЯ ГЛУБИНА

Слой 03: translate 1–3 px
Слой 04: translate 3–5 px
Слой 01: translate 5–8 px
Слой 05: translate 8–12 px

Не надо вращать объект сильно. Максимум:
rotateX ±1.5deg
rotateY ±2deg
scale 1.00–1.02

Для мобильной версии лучше привязать лёгкое движение к скроллу, а не к курсору.

ПРОМТ ДЛЯ CODEX

Собери 2.5D-композицию для мобильного лендинга Rumi из ассетов в этой папке.

Порядок слоёв:
1. 03-background-glow.png
2. 04-background-organic-shape.png
3. 02-masha-billy-shadow.png
4. 01-masha-billy-main.png
5. 05-foreground-leaves.png

Главный объект должен оставаться визуально статичным и реалистичным. Не делай эффект вращающейся 3D-модели.
Добавь только очень лёгкий параллакс и ощущение глубины.
На мобильных устройствах используй scroll-based parallax с небольшими смещениями.
На desktop можно добавить мягкую реакцию на курсор.
Учитывай prefers-reduced-motion и полностью отключай эффект для пользователей с reduced motion.
Не допускай горизонтального скролла.
Сохраняй композицию адаптивной: Маша и Билли должны оставаться главным визуальным центром.
